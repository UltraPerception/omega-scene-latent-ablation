# VGGT-Omega scene latent covariance: dataset ablation

[Open the dashboard](https://ultraperception.github.io/omega-scene-latent-ablation/)

An interactive report comparing training data mixtures across six test datasets.

## Explore

- Compare all training combinations on one test dataset.
- Select one training combination to view its performance on all six test datasets.
- Filter added training sources by their C1–C6 category.
- Share a selected view using its URL; selection survives refresh.
- Download metric CSVs, category metadata and public result summaries.

## Experiment

- Frozen VGGT-Omega backbone with an ordinary scene latent covariance head.
- 24 training configurations, 10,000 optimizer steps each, 8 H200 GPUs per run.
- A round: 16 configurations. A00 is 100% TartanAirV2; A01–A15 use 50% TartanAirV2 and 50% one added source.
- B round: eight multi-source configurations. B01–B06 use 50% TartanAirV2 with the remaining 50% split equally among two or three selected sources. B07 samples all 16 sources equally (6.25% each). B08 uses 50% TartanAirV2 and splits the remaining 50% equally among the other 15 sources.
- Mixture shares are targets measured by sampled windows; the fixed finite-window schedule applies integer quota rounding.
- Filter all 24 configurations or select one experiment round. Exact per-run target shares and C1–C6 categories appear in the dashboard.
- Tests: 7Scenes, held-out AV2 logs, KITTI05, TUM Dynamic, ETH3D and EuRoC.
- Metrics: joint NLL; joint, translation and rotation ANEES; translation and rotation Spearman.
- The dashboard uses N=10. Downloaded result JSON also contains the available N=32 summaries.
- Sequence/group/dataset aggregation uses medians. No cross-dataset NLL average or composite score is produced.
- One training run per configuration; differences do not establish multi-seed statistical significance.

## Publishing

GitHub Pages serves the `main` branch root. `.nojekyll` enables direct static-file hosting.
No dependencies, build step or server are required. Both `index.html` and `report.html` support shared view URLs.

The export is generated by `scripts/export_omega_ablation_pages.py` in the VGGT-Sigma workspace. Its default export merges both campaigns. Use repeated `--campaign` arguments to choose explicit campaigns, then commit and push the updated report files to publish a newer snapshot.
